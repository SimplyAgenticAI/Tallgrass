Install it by hand instead

Only worth doing if the store build is behind this dashboard (store copies lag by a review cycle) or your Chrome profile blocks store installs. The hand-loaded copy does not update itself.

1
Download the extension

A zip containing the extension files.

Download extension (v{{ extension_version }})

Carries this dashboard's address, and no credentials — so it's safe to pass on, and downloading it again won't disconnect anything.

2
Unzip it somewhere permanent

Chrome reads these files off disk every time it starts, so don't leave it in Downloads and clear it later. Documents is fine.

3
Open Chrome's extensions page

One click copies the address, then two keys and Enter get you there.

{% include "_open_extensions.html" %}
4
Turn on Developer mode

Top-right corner. Without it there's no way to load the extension at all.

{% include "_diagram_devmode.html" %}
5
Drag the unzipped folder onto the page

Drag the folder itself — not the zip, not the files inside it — straight onto the Chrome window.

{% include "_diagram_drag.html" %}

Prefer buttons? Click Load unpacked and select the unzipped folder.

Updating a hand-loaded copy: download a fresh zip, unzip it over the same folder, then click the reload arrow on the extension card at chrome://extensions. The store copy does this by itself.
