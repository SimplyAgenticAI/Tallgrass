{# Getting somebody to chrome://extensions. This wants to be a link and cannot be one. Chrome blocks every web page from navigating to its own settings pages, and it blocks them silently: an renders like a link, hovers like a link, and does absolutely nothing when clicked. No error, no new tab, no clue. That is worse than no link, because the visitor concludes the install is broken rather than that they need to paste something. window.open, location.href, target=_blank and a right-click "open in new tab" are all refused the same way. There is no page-side trick left; the only thing that can open that URL is the person's own address bar. So: one obvious button that puts the URL on the clipboard, and the moment it lands, the exact keystrokes that finish the job. Two keys and Enter, with nothing to read off the screen and retype. The modifier is written as Ctrl in the markup and corrected to the Command symbol by outlier.js on a Mac, so it is right before the script runs and righter after. #}
{# Kept visible rather than hidden behind the button: somebody who would rather type it, or who has the clipboard locked down, still needs to be able to read it. #}
chrome://extensions

Copied. Now, in this window:

  1. Ctrl L jumps to the address bar
  2. Ctrl V pastes the address
  3. Enter opens the extensions page

Chrome won't let a website open its own settings, so this last bit has to be pasted. It's the only step Tallgrass can't do for you.
